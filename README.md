# Faísca Dating

Um app de namoro barato, chamativo e prático, inspirado no Tinder, com foco em conexões reais em João Pessoa/PB.

## Features Planejadas
- Swipe rápido com limite generoso grátis
- Perfis divertidos com prompts locais
- Integração com IA pra icebreakers

## Tech Stack
- React Native + Expo
- Firebase pra backend

## Como Rodar
1. Clone o repo: `git clone https://github.com/Yagoiorlon/faisca-dating.git`
2. Instale dependências: `npm install`
3. Rode: `expo start`
